# Choir Notes

A choir-first browser notation editor built for quick a cappella arranging.

## Current features

- SAB, SATB, and TTBB score templates
- Two voices per staff
- Notes, rests, dots, and accidentals
- Lyrics attached to notes
- Full-score and individual-part playback
- Browser autosave and undo
- LilyPond export

## Run it

Open `index.html` in a modern browser. No installation or build step is required.

## Project status

Choir Notes is an early working prototype. The notation and export systems are still being developed.
